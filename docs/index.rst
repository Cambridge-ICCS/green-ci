green-ci
========

The ``green-ci`` project encourages the use of green software engineering
practices in continuous integration (CI) and continuous deployment (CD)
workflows implemented with GitHub Actions. It provides
`documentation <best-practices>`__ and templates on how to optimise CI/CD
pipelines to reduce energy consumption, minimise resource usage, and promote
sustainable software development practices. By adopting these strategies,
developers can reduce the carbon footprint of their work and contribute to
environmentally friendly software engineering while maintaining efficient and
reliable CI/CD processes.

The ``green-ci`` tool can be found on GitHub at
https://github.com/Cambridge-ICCS/green-ci.
